* JOYCON = 3
* VOLUME UP (VOL+) = 0
* USB-SPANNUNG (USB VOLTAGE) = 2
* USB DATA - (RECHTES PAD) = MICRO-USB PIN 2
* USB DATA + (LINKES PAD) = MICRO-USB PIN 3
* 3V DC = 3V
* GND = GND
* RESET = N/A (Nicht zutreffend)
